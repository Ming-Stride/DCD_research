# DCD_research
R code for Developmental Coordination Disorder (DCD) research

## Project description
This repository contains R scripts for data cleaning, statistical analysis and visualization in DCD related study, including EMG processing, muscle synergy extraction and gait analysis.

## Folder structure
- `R/`: R source scripts
- `figures/`: Generated plots and figures
- `docs/`: Document and manuscript materials

## Notes
Raw dataset is NOT included in this repo due to data volume and privacy concerns.
